I first checked the sample game and got to know what mechanics have to be built for the game. Then I planned the project using ChatGPT, keeping the guardrails in mind. I created a phase by phase development plan which makes it easy to test the game after every phase rather than building all in one go and then testing everything later. This approach helps to minimise bugs later on and keeps game quality in check.
I was able to build the entire game in 9 phases. The player movement was not implement properly so I had to intervene and ask Codex to fix it. The game felt a little easier so I introduced a new mechanic in which player had to monitor their fuel level which will drain as the player plays the game. Player could also pick up fuel. I also asked Codex to implement background music, bullet firing and hit sounds, enemy wave approaching audio to make it more engaging.
Added a mechanic where an enemy would come out of the wave(in intervals) and approach faster towards the player.
Future scope can include multiple enemy and spaceship types, power-ups, high score persistence and combos.
